# Dolev AI — Twitter Stock Trend Agent (Phase 1)

Watches finance Twitter via Playwright, scores tickers using FinBERT sentiment + credibility-weighted trust graph, and fires structured trade-signal alerts to Telegram when conviction crosses a threshold.

Phase 2 (autonomous order execution via Alpaca/IBKR) consumes the same `Signal` objects this phase emits.

## Quick start

```bash
# 1. Install dependencies
pip install -e ".[dev]"
playwright install chromium

# 2. Copy env vars
cp .env.example .env
# Edit .env with your keys

# 3. Download NYSE + NASDAQ universe
python scripts/download_universe.py

# 4. Log in to X once (stores session in browser_profile/)
python scripts/login_x.py

# 5. Run in dry-run mode (alerts print to stdout, no Telegram)
python -m dolev_ai.main --dry-run

# 6. Run live
python -m dolev_ai.main
```

## Architecture

```
Playwright (X scraper)
  → TickerExtractor + FinBERT sentiment + credibility weighting
  → rolling per-ticker score aggregation
  → TrustGraphStrategy threshold check
  → Claude synthesizer (rationale + conviction)
  → Telegram alert
  → SQLite persistence
```

## Configuration

- `config/seeds.yaml` — curated finance accounts (tier 1/2/3)
- `config/settings.yaml` — thresholds, poll cadences, cooldowns
- `config/universe.csv` — generated by `scripts/download_universe.py`

## Project structure

```
src/dolev_ai/
  main.py              asyncio daemon
  models.py            dataclasses: Tweet, Account, TickerScore, Signal
  db.py                SQLAlchemy + SQLite
  sources/             TweetSource ABC + PlaywrightSource
  strategies/          SignalStrategy ABC + TrustGraphStrategy
  analysis/            ticker extraction, sentiment, credibility, aggregation
  synth/               Claude synthesizer
  alert/               Telegram alerter
scripts/
  download_universe.py fetch NYSE + NASDAQ symbol lists
  login_x.py           one-time X login via headful browser
tests/
```
